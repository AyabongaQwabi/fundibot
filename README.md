# Fundibot

Free tools for South African Grade 12 students to find institutions, courses, and career guidance.

## Tools

- **University Qualification Checker**: Calculate APS score and find matching institutions
- **Course & Institution Finder**: Search for courses by province
- **Career & Course Recommender**: Get career paths based on subjects and marks

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Data

Institution and programme data is loaded from `seed/final/claude/merged/`.

## Build

```bash
npm run build
npm start
```
